# TeamDesk · 数字班组工作台

给 3-10 人小团队的内部 AI 班组：5 名"数字员工"按 SOP 干重复性分析杂活（报表洞察 / 制度问答 / 会议纪要 / 文案优化 / 评论舆情），全程留痕、关键动作人工审批、绩效可看。**没有 LLM key 也能完整跑通全部演示。**

## 快速开始（3 行）

```bash
# 方式一：docker（推荐）
./scripts.sh up                  # → 打开 http://localhost:8321

# 方式二：本地直跑（需 python3.11+/uv；前端就绪后自动带上 :8321）
./scripts.sh sample && ./scripts.sh dev

# 想接真模型：cp .env.example .env 后填 LLM_API_KEY（OpenAI 兼容接口均可）
# （装有 make 的环境可互换使用 make {up|dev|sample|kill}）
```

## 功能清单

- **5 名数字员工 + 调度长**：每人有 JD、权限矩阵（自主/审批/禁止）、独立模型配置与绩效指标
- **SOP 引擎**：任务 → Run → Step 状态机；关键动作（如"对外发送"）自动插审批闸门，人工批准才放行
- **企业知识库（RAG）**：上传 txt/md/pdf/xlsx/csv 自动切块入库；制度问答必须带出处引用
- **报表 AI 分析**：投放报表 → 趋势/异常洞察 + ECharts 图表 + 风险分级提示（ACOS 突变告警）
- **评论 VOC**：200 条评论 → TOP-N 主题占比 + 代表原声 + 改进建议
- **会议纪要**：周会记录 → 纪要 + 行动项表（事项/负责人/期限）
- **管理驾驶舱**：tokens 花费趋势、per-employee 成功率/耗时、审批留痕全审计
- **离线模式**：无 key 时自动降级（pandas 统计 / 哈希嵌入 RAG / 关键词分桶），reasoning 标注 `[离线模式]`

## 演示剧本（5 条，无 key 全绿）

1. 拖入 `data/ad_report.xlsx` → 阿数（报表分析师）→ 3 条洞察 + 花费/ACOS 双轴图 + **ACOS 28%→55% 突变高风险提示** → 触发"对外发送管理层"审批
2. 输入「破损包裹怎么理赔？」→ 老查（文档问答官）→ 回答 + 引用《退换货政策》具体条款
3. 拖入 `data/reviews.csv` → 听风（VOC 舆情员）→ TOP3 主题（物流慢/包装破损/客服差）+ 占比 + 代表原声
4. 拖入 `data/meeting_notes.md` → 小纪（纪要秘书）→ 纪要摘要 + 4 条行动项表（含负责人与期限）
5. 在剧本 1 的审批浮层点「批准」→ Run 收尾 completed；点「拒绝」→ Run 终止为 error(rejected)，全程留痕可回放

└───────────────────────────────────────────────────────────────────────────────────┘

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | FastAPI · SQLAlchemy 2.0 async · SQLite · SSE · pandas · numpy |
| Agent | 自研 SOP 状态机 + Agent 契约（BaseAgent/AgentResult），规则兜底降级 |
| RAG | 字符 n-gram 哈希嵌入（零依赖）/ bge-small-zh（可选） |
| 前端 | React 18 + TypeScript + Vite + Tailwind + ECharts |
| 部署 | Docker Compose（backend python:3.11-slim / frontend node:22→nginx:alpine） |
